本项目会实现多个以深度学习为主的RL算法，包括：

- Actor-Critic
- DQN
- Soft Actor-Critic
- CURL（表征模型）

它们都会搭建一套神经网络模型，而搞清楚它们模型的具体架构非常重要。

本项目的强化学习任务是：根据视觉图像训练智能体，即输入到模型的是图像。这自然而然地想到卷积神经网络，这引入如下问题：

1. 输入模型的图像如何处理：灰度处理、裁剪？
2. 模型的具体架构、深度如何设置？

文献原文中可能有所提及，需要阅读文献确认上面的问题。最终在docs/reports/文件夹下编写一份模型架构文档，包括上面4种模型的架构。

特别的是，CURL指的是它的表征模型，即将图像进行降维处理为表征向量的编码器。
