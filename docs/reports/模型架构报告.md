# 模型架构报告（AC / DQN / SAC / CURL）

本文覆盖：基线 AC / SAC / DQN（端到端像素网络）、CURL 表征编码器 f_q、以及 CURL 接入各算法后的变体（CURL+X）。给出各网络的逐层规格与数据流；训练目标（熵正则、温度、对比损失、EMA key encoder 等）不在层范围内。

## 1. 输入观测管线

| 项 | DMControl 域（连续，walker-walk） | ALE 域（离散，BattleZone） |
|---|---|---|
| 原始渲染 | `physics.render` `(100,100,3) uint8` | 原生观测 `(210,160,3) uint8` |
| 预处理 | 训练随机 crop / 评估中心 crop → 84×84 | 灰度 + 等比缩放 → 84×84 |
| 像素归一 | ×(1/255) | ×(1/255) |
| 帧栈 | RGB×3 | 灰度×4 |
| 入网形状 | `(9,84,84)` | `(4,84,84)` |

resize / crop 均在入网前完成，网络只接触 84×84 输入。

## 2. 卷积特征段（结构定义）

各引用它的网络实例化时自建参数（不共享可训练实例）。

### 2.1 连续域卷积段 C_dmc（AC / SAC / f_q 同构复用）

输入 `(9,84,84)`，全部 `padding=0`，每卷积后 ReLU：

| # | 操作 | 输出形状 |
|---|---|---|
| c1 | Conv2d(k=3, s=2) 9→32 | (32,41,41) |
| c2 | Conv2d(k=3, s=1) 32→32 | (32,39,39) |
| c3 | Conv2d(k=3, s=1) 32→32 | (32,37,37) |
| c4 | Conv2d(k=3, s=1) 32→32 | (32,35,35) |
| flat | Flatten() | 39200 |

### 2.2 离散域卷积段 C_ale（DQN 前端，同构复用）

输入 `(4,84,84)`，`padding=0`，每卷积后 ReLU：

| # | 操作 | 输出形状 |
|---|---|---|
| c1 | Conv2d(k=5, s=5) 4→32 | (32,16,16) |
| c2 | Conv2d(k=5, s=5) 32→64 | (64,3,3) |
| flat | Flatten() | 576 |

## 3. 基线网络（端到端，不经 latent 瓶颈）

### 3.1 Actor-Critic（连续，动作 6 维）

```
obs(9,84,84) → C_dmc(39200) → Linear 39200→1024 + ReLU ⇒ h(1024)
  → μ(6)、log_std(6)     （tanh 重参数采样在训练层处理）
  → V(s)(1)
```

| # | 操作 | in→out |
|---|---|---|
| 特征层 | Linear(39200→1024) + ReLU | 39200→1024 |
| p1 | Linear(1024→256) + ReLU | 1024→256 |
| p2 | Linear(256→6)（μ） | 256→6 |
| p3 | Linear(256→6)（log_std，初始化为 0） | 256→6 |
| v1 | Linear(1024→256) + ReLU | 1024→256 |
| v2 | Linear(256→1) | 256→1 ⇒ V(s) |

### 3.2 SAC（连续，动作 6 维）

数据流同 §3.1 至 `h(1024)`，actor 结构同 §3.1 p1–p3；critic 为双 Q 独立实例，输入 concat 动作：

```
critic: concat(h(1024), a(6)) = 1030 → 256 → 1
```

| # | 操作 | in→out |
|---|---|---|
| ct1 | Linear(1030→256) + ReLU（Q1、Q2 各一实例） | 1030→256 |
| ct2 | Linear(256→1) | 256→1 ⇒ Q(s,a) |

### 3.3 DQN（离散，18 动作）

```
obs(4,84,84) → C_ale(576) → Linear 576→256 + ReLU
  → V 头(256→1)、A 头(256→18)
Q(s,a) = V(s) + (A(s) − mean_a A(s))
```

| # | 操作 | in→out |
|---|---|---|
| fc | Linear(576→256) + ReLU | 576→256 |
| V 头 | Linear(256→1) | 256→1 |
| A 头 | Linear(256→18) | 256→18 |

## 4. CURL 表征编码器 f_q

```
obs(9,84,84) → C_dmc(39200)
  → Linear 39200→1024 + ReLU → Linear 1024→50 → LayerNorm → tanh ⇒ z(50)
```

| # | 操作 | in→out |
|---|---|---|
| f1 | Linear(39200→1024) + ReLU | 39200→1024 |
| f2 | Linear(1024→50) | 1024→50 |
| f3 | LayerNorm(50) | 50→50 |
| f4 | tanh | 50→50 ⇒ 表征向量 z |

输出 z(50) 用作 CURL+X 各 RL 头的输入与 InfoNCE 锚点；key encoder（EMA）、bilinear 相似度矩阵 W、InfoNCE 更新为训练侧机制。

## 5. CURL+X 接入变体

变体的卷积段与基线 X 同构，差异仅在 flatten 后接入 f_q 表征尾巴，RL 头建于 z(50) 之上。离散域 CURL+DQN 中 f_q 前端改为 C_ale。

### 5.1 CURL+AC

```
obs(9,84,84) → C_dmc → 1024 → 50 → LN → tanh ⇒ z(50)
  → μ(6)、log_std(6)
  → V(s)(1)
```

| # | 操作 | in→out |
|---|---|---|
| p1 | Linear(50→256) + ReLU | 50→256 |
| p2 | Linear(256→6)（μ） | 256→6 |
| p3 | Linear(256→6)（log_std，初始化为 0） | 256→6 |
| v1 | Linear(50→256) + ReLU | 50→256 |
| v2 | Linear(256→1) | 256→1 ⇒ V(s) |

### 5.2 CURL+SAC

数据流同 §5.1 至 `z(50)`，actor 结构同 §5.1 p1–p3；critic 双 Q 独立实例：

```
critic: concat(z(50), a(6)) = 56 → 256 → 1
```

| # | 操作 | in→out |
|---|---|---|
| ct1 | Linear(56→256) + ReLU（Q1、Q2 各一实例） | 56→256 |
| ct2 | Linear(256→1) | 256→1 ⇒ Q(s,a) |

### 5.3 CURL+DQN

```
obs(4,84,84) → C_ale(576) → Linear 576→256 + ReLU
  → Linear 256→50 → LayerNorm → tanh ⇒ z(50)
  → V 头(50→1)、A 头(50→18)
Q(s,a) = V(s) + (A(s) − mean_a A(s))
```

| # | 操作 | in→out |
|---|---|---|
| fc | Linear(576→256) + ReLU | 576→256 |
| 投影 | Linear(256→50) + LayerNorm(50) + tanh | 256→50 ⇒ z |
| V 头 | Linear(50→1) | 50→1 |
| A 头 | Linear(50→18) | 50→18 |
